# Agent work

If a `teammates/` folder is present, it's the owner's local agent harness (not part of this repository). Route agent work through `teammates/README.md`: start as the PM unless the owner named another role, pick the project or one-off, and read its `assignment.md`, `decisions.md` and `state.md`.

# Personal Ride Lab work

For a request to **resume the rider epic**, start at [docs/ride-lab/README.md](docs/ride-lab/README.md), then read its active epic and resume state (and the `ride-lab-rider` project in `teammates/`, when present).

That map owns task progress, current source assets and the next action. Update it at handoff; preserve the accepted scooter and archived character originals. Consult the linked authoring workspace's applicable instructions before operating Blender. At epic completion, keep the entry point and redirect it to the final handoff and archived map.
